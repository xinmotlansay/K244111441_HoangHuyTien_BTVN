# Bài tập Web 2

- **Bài 13:** danh sách sản phẩm, hình ảnh và trang chi tiết.
- **Bài 14:** danh mục và sản phẩm bằng service và ngFor lồng nhau.
- **Bài 18:** khách hàng theo nhóm, đọc JSON qua HttpClient.

## Cách chạy

Mở terminal trong thư mục bài muốn chạy, ví dụ:

```bash
cd bai-18
npm ci
npm start
```

Mở địa chỉ được hiển thị trong terminal. Nhấn Control + C để dừng.
Chạy `npm run build` trong từng thư mục để biên dịch.
